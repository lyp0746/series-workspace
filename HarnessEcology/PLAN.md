# 被点燃的生态 — 论文计划（新会话从这里开始）

> 题目：**被点燃的生态：两个社区、五种口径与三个标记**
> 英文：*An Ignited Ecosystem: Two Communities, Five Resolutions, Three Markers*
> 作者：李毅芃　·　日期：2026-10-23　·　CC BY 4.0

---

## 一句话主张

一个平台公告可以在两天内点燃一条 topic 线，但这不构成"涌现"。用《涌现的临界》的三标记去核，
得到的不是判决而是**判据不适用**——因为序参量、事前窗口、逐仓库面板三样数据都取不到；
而同一批数据在五种口径下给出两个相反方向，说明这类问题上**口径的选择比数据的解释更决定结论**。

## 命题与失败条件（先写死，再看数据）

| 编号 | 命题 | 什么结果算撤回 |
|---|---|---|
| P1 | Harness 新增曲线的数量级跳变与官方仓库创建日（2026-08-13）对齐，属外部冲击响应，不是自组织越过临界 | 若跳变日与发布日相差 ≥3 天，或发布前已有同等量级的日新增，P1 撤回 |
| P2 | 按三标记，本案至多中一个；因此不能称"质变" | 若能在本案测出"事前慢化"（冲击前方差/自相关显著上升）或"宏观更好用"（Φ>0），P2 撤回 |
| P3 | "Harness 与配套 skills 社区"这个说法在结构上不成立：两条 topic 线的重叠率极低 | 若重叠 ≥20%（Jaccard），P3 撤回 |
| P4 | 分辨率改变结论符号：星标门槛从 0 提到 10，10 月的"回升"变"继续下降" | 若三档门槛下符号一致，P4 撤回 |

结果：P1 支持、P2 支持（判据不适用）、P3 支持（0.7%）、P4 支持（交叉点在 ★≥1 与 ★≥10 之间）。

## 数据

- GitHub 公开搜索接口，`topic:dsh-plugin` / `topic:agent-skills`，按 `created` 分桶。
- **103 条搜索查询 + 5 条 core API 查询**，含 19 天日尺度（2026-08-06—08-24）、5 个 Harness 期段、
  14 个 skills 期段、五档星标门槛、两条线交集、两个"回溯贴标"探针、8 条星标阶梯、24 条存活率。
- 快照时间 2026-10-23。**计数是活数据，会变**；每条查询的抓取时刻都记录在 `data/raw/*.json`。
- 已知偏差：标签可事后添加；已删除仓库不可见；star 门槛对新仓库不利；短尾月。
- 被放弃的路径：逐仓库抽样（搜索接口只支持 stars/forks/updated 排序，必有选择偏差）→ 退回计数。
