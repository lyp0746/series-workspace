# 被点燃的生态：两个社区、五种口径与三个标记

**DeepSeek Harness 与 agent-skills 两条 topic 线的增长形态，以及"分辨率"如何决定你看见哪一种涌现**

李毅芃 · 2026-10-24 · 工作论文（24 页，10 图，7 表 + 表 A1，CC BY 4.0）

*An Ignited Ecosystem: Two Communities, Five Resolutions, Three Markers*

## 一句话

用 103 条 GitHub 公开接口查询检验"社区涌现是否一场质变"，结论是**判据不适用**——因为序参量、事前窗口、逐仓库面板三样数据都取不到；而同一批数据在五种口径下给出两个相反方向，说明在这类问题上，**口径的选择比数据的解释更决定结论**。

## 三条主结果

1. **跳变对齐外部冲击，不满足"从无到有"。** 发布日 2026-08-13：日新建 38 → 615 → 峰值 1,841（48 倍），但发布前 7 天的基线是 23.9/日，不是零；651 个"发布前"仓库里有 47 个创建于 2026 年之前——基线是回溯贴标，不是先前的活动。
2. **五种口径，两个方向。** 9 月→10 月：原始日均 +62%、★≥10 −36%、★≥100 −19%、队列存活率 +46%、合格率 −61%。跨度 123 个百分点，远大于数据误差。
3. **"配套"是叙事，不是结构。** 两条 topic 线只重叠 414 个仓库（Jaccard 0.7%）；dsh 星标榜前 50 名里有 35 个（70%）出生在划线之前。

## 三条负面结果

- **F1** 序参量不可判：没有仓库间关系数据，日增流量不能冒充状态量。
- **F2** 事前慢化不可测：事前窗口只有 7 天且被回溯贴标污染；平台型生态里"恢复时间"可能根本不存在。
- **F3** 合格率下降无法归因：贴标膨胀与年龄偏差同向，截面数据分不开。

另有 F4（抽样路径失败，改为计数）、F5（08-20 与 10 月的两次回升原因未核）。

## 方法上留下的东西

- **可测性门槛**：进三标记之前，先问三个量各自取不取得到；取不到记"不可判"，不进判定表。否则"三中二"会把"数据不足"误报成"证据不足"。
- **一条可复用的报告纪律**：报增长率至少报两档星标门槛，并报交叉点在哪里。
- **三种失败模式**：强度量冒充序参量 / 后事污染事前 / 出生史冒充入籍史。

## 边界

计数不是行为，标签不是社区，快照不是面板。本文只覆盖一个平台上的两个 topic 线；不提供对任何具体平台的政策判断。计数是活数据：重跑会得到略大的数，因此 `data/raw/` 里的抓取时刻是结果的一部分。
