# 锚点的下限：情景记忆的模拟对照实验与 0.57 的覆盖率阈值

**一个可复算的替身实验：三层记忆架构在什么条件下有效，在什么条件下不如一张摘要**

李毅芃 · 2026-10-26 · 工作论文（51 页，CC BY 4.0）

*The Floor of Anchoring: A Simulation Study of Episodic Memory and the 0.57 Coverage Threshold*

---

## 一句话

上一篇把「这套架构能不能让 Agent 不死」撤回了，因为没实验。这篇去跑：**12000 步模拟、四条预先登记的否证条件、一条被自己的实验打中**。结论不是「三层架构更好」，而是——**在锚点覆盖率达到约 0.57 之前，它比一张摘要更差；过了这条线才开始赢。而且允许回写会让准确率在 200 步内掉一半。**

## 摘要

实验的性质必须先说清：**这是机制模拟，不是 LLM 实验。** 环境（五个页面、两个表面标签）、日志、重建者、裁判全部由代码定义，参数显式（出错率 p、共源度 ρ、路数 K、锚点覆盖率 cover）。它能回答「架构的内部逻辑是否成立、边界在哪」，不能回答「某个模型在真实账号上如何表现」。

六个结果。**一**，主对照（覆盖率 0.5）：情景唤起准确率 **0.441**，摘要 0.339，无记忆 0.000；跨页面污染率 0.179／**0.625**／0.187——**最危险的不是「没有记忆」，是「一张丢掉了 app 与 screen 的摘要」（0.625，是无记忆的 3.3 倍）**。**二**，但误动作率上情景唤起（0.209）**并未**胜过摘要（0.196）——预注册的 F1 **部分触发**。**三**，覆盖率扫描给出交叉点 **0.569**（对种子自举的 95% 区间 **0.44–0.74**）：**低于它不如摘要，高于它才开始赢**。**四**，允许把重建结果回写账本（M2w）时，准确率 200 步内从 0.338 掉到 0.151，误动作从 0.209 升到 0.273，而人环次数反而下降——**污染让系统更自信**。**五**，ρ 从 0 到 0.7：误动作 0.092→0.118、人环 0.55→2.40；K 的收益在 3 处饱和（K=5 只再降 0.001，延迟多 554 ms）。**六**，p 从 0.15 到 0.35 只让误动作 0.106→0.110，而覆盖率 0.5→0.9 让它 0.210→0.080——**补账本比换模型便宜，也更有效（32 倍）**。

四条否证条件：**一条部分触发（F1）、三条未触发**。本文十条命题：八条支持、一条未检验（T9 仍撤回）、**一条撤回**（T10：「0.57 是可迁移常数」——换参数移动 ±0.10，自举区间 0.44–0.74）。

## 三条读前须知

1. **所有结论都是 C 级。** 模拟给的是边界，不是证据（正文 10.3）。
2. **0.57 不是常数。** 它是一次读数的位置；区间 0.44–0.74，换参数再移动 ±0.10。
3. **主对照那一组参数是对本文不利的**（覆盖率只有 0.5），而它恰好打中了 F1——这不是失误，是设计：**报不利的那一组，是自证清白最便宜的方式。**
