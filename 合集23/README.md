## 版式三条硬规则（踩过坑）

1. **页尺寸**：Playwright `format="A4"/"B5"` + `prefer_css_page_size=True`；Chrome CLI 会退回 Letter。
2. **封面满版**：`@page { margin: 25mm 28mm }` + `.cover` 负边距抵消版心；不用具名页（本机不稳）。
3. **正文居中**：`max-width: none` 覆盖 `paper.css` 的 145mm，让正文填满版心。
