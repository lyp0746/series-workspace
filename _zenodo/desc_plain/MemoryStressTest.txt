中文摘要。上一篇《记忆的锚点》提出三层记忆架构（书记员字段级硬日志／异构重建／带锚裁决），并把自己的关键命题 T9「能把几天延长到几周」撤回，因为没有实验。本文把那套架构实现成可复算的机制模拟，去回答一个更窄的问题：它在什么条件下才比一张摘要更好？配置：5 个页面 × 2 个表面标签（负迁移陷阱）× 4 个条件（M0 无记忆／M1 摘要／M2 情景／M2w 允许回写），12000 步主对照、80000 步覆盖率扫描、81 组敏感性，另有四条预先登记的否证条件。

主要结果。（1）准确率：情景 0.441 ＞ 摘要 0.339 ＞ 无记忆 0.000；但跨页面污染率是 摘要 0.625、无记忆 0.187、情景 0.179——摘要是最危险的记忆，污染是「无记忆」的 3.3 倍。（2）自我打击一条：情景在不可逆动作上并未胜过摘要（误动作 0.209 对 0.196），预注册的 F1 部分触发。（3）覆盖率扫描给出交叉点 0.569（自举 95% 区间 0.44—0.74）：低于它不如摘要，高于它才开始赢；换参数后阈值移动约 ±0.10，因此 0.57 不是常数。（4）允许重建回写（M2w）：200 步内准确率 0.338→0.151、误动作 0.209→0.273，而人环转介反而下降——污染让系统更自信，这是「重建不得回写账本」的量化版本。（5）相关 ρ 从 0 到 0.7：误动作 0.092→0.118、人环 0.55→2.40；集成规模 K 的收益在 K=3 处饱和（K=5 只再降 0.001，代价 +554 ms）。（6）参数 vs 覆盖率：把采样量提高到三倍，误动作只从 0.106 变到 0.110（几乎不动）；而覆盖率 0.5→0.9 让它 0.210→0.080（约 32 倍）——补账本比换模型有效。十条命题：八支持、一未检验（T9 仍撤回）、一撤回（T10：0.57 不可迁移）。

贡献。本件的贡献有三：把「锚点的下限」写成可检验的条件；给出可复算的读数或结构；公开边界、失败与撤回。

边界。这是机制模拟，不是 LLM 实验。环境、日志、重建与裁决全部由代码定义，因此结论只对「这套机制」成立，不外推到真实模型；T9（能延长真实账号存活）仍为未检验。另有两处教训写在正文：一次失败的 M1 设计，一次参数误设；并附 ODD 九项自查与「如果重做会改哪三处」。

Abstract.A recomputable mechanism simulation of the three-layer memory architecture proposed in the previous paper: five screens with two surface labels (a negative-transfer trap), four conditions (no memory / summary / episodic / episodic with write-back), 12,000 main steps, an 80,000-step coverage sweep, an 81-cell sensitivity grid, and four preregistered falsification conditions. This is a simulation of the mechanism, not an LLM experiment. Episodic recall reaches accuracy 0.441 against 0.339 for a summary and 0.000 for no memory, yet does not beat the summary on irreversible-action errors (0.209 vs 0.196), so the preregistered F1 is partially triggered. Cross-page contamination is 0.625 for the summary — 3.3 times that of no memory — against 0.187 for no memory and 0.179 for episodic recall: the summary is the most dangerous memory. The coverage crossover is 0.569 (bootstrap 95% interval 0.44–0.74), and it moves by about ±0.10 when parameters change, so 0.57 is not a constant. Allowing reconstructions to be written back to the log halves accuracy within 200 steps while reducing human escalation: contamination makes the system more confident. Correlation rho from 0 to 0.7 worsens both accuracy and cost; the ensemble gain saturates at K = 3; and raising coverage from 0.5 to 0.9 cuts the irreversible-action rate from 0.210 to 0.080, far more than tripling the sample rate does — improving the ledger beats upgrading the model. Of ten propositions, eight are supported, one remains untested (T9 stays withdrawn) and one is withdrawn (T10: 0.57 is not transferable).
