# 有限系统的取舍：系列合集

**九本书 + 十五篇工作论文，附卷首一篇**　｜　李毅芃　｜　2026-11-05

*The Tradeoffs of Finite Systems: A Twenty-Four-Item Collection*

---

## 一句话

九本专著、十五篇工作论文，放在同一张桌子上，只为了看清一件事：**一个有限的东西，怎样一边保持自己的样子，一边还能改变？**

## 合集包含什么

| 部 | 内容 |
|---|---|
| 第一部 | 九卷专著：导览、语言、容量、时间、取舍、诠释、临界、全应用、应用 |
| 第二部 | 实证论文一—六：术语、分期、残余、驿道、官制、生态 |
| 第三部 | 方法论文七—十三：优化、代理、剖面、同构、锚点、下限、两层 |
| 第四部 | 跨域论文十四：量子力学与广义相对论的接缝 |
| 阶段总账 | 论文十五：126 条登记命题的对账（覆盖一—十五） |

每卷保留单行本的封面、版权页、目录、前言与结语；每篇论文保留题名页、作者行、图表与附录。论文编号按阅读顺序连续排列，与 DOI 发布顺序无关。

→ 第一部 九卷 → 第二部 实证（一—六）→ 第三部 方法（七—十三）→ 第四部 跨域（十四）→ 阶段总账（十五，覆盖一—十五）→ 后记 → 版本记
