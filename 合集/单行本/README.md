# 单行本（宣纸·朱砂版）

两本小书，与《粗码》《合集》同一套视觉语言：暖白宣纸底、宋体正文、楷体诗行、
朱砂印章、章首不印页眉。A4，可直接双面打印装订。

| 书 | 源 | 页数 | 产物 |
|---|---|---|---|
| 《中道周行集》 | `中道周行集.md` | 9 | `out/中道周行集.pdf` |
| 《得鹿梦鱼》 | `得鹿梦鱼.md` ＋ `图1—图5.jpg` | 27 | `out/得鹿梦鱼…pdf` |
| 合一版（卷首＋粗码） | 上二者 ＋ 粗码 `output/book.pdf` | 809 | `../../resolution-grain/release/resolution-grain-print.pdf` |

**两份源都是 md，没有 docx。** `得鹿梦鱼.md` 由 `convert_sanwen.py` 从 docx 一次性转出，
此后改字改 md；docx 已删除。

## 重建

```bash
python build_zhongdao.py              # 单行本 PDF
python build_zhongdao.py --fragment   # 顺带重写 ../\_front_daozhou.html（合集卷首）
python build_sanwen.py                # 散文单册（阿拉伯页码 1—）
python make_combined.py               # 合一版 → 粗码的 release/（先跑粗码 build_book --pdf）
```

`--fragment` 是刻意做的：合集卷首《中道周行集》与单行本必须**同一份文字**。

`build_sanwen.py` 另有三个开关：`--no-cover`（不排封面）、`--roman`（罗马页码）、
`--out PATH`。合一版就是这三者合起来的产物。

## 文件各管什么

- `common.py` —— 共用版式：字体注册、宣纸/朱砂配色、装饰件（星菱线、朱砂印（四字／两字）、
  卷题栏线、图版 `Plate`）、`BookCanvas`（底色／页眉／页码／书签／不出空白尾页）、段落样式。
  两个全局开关：`CFG["folio"]`（arabic｜roman）、`CFG["cover_pages"]`（前几页算封面）。
  另外补了 reportlab 的**中文标点禁则**（`；，：！？—` 不许起行）。
- `build_zhongdao.py` —— `##` 分体，`P`／`V`／`TI`／`SIGN`／`ORN`／`FLOW` 六种行。
  四言／五言／骚体自动疏排；词与骈走左对齐（`verse_ci` 11.2pt）。`--fragment` 出合集卷首。
- `build_sanwen.py` —— `##` 分节，`P`／`Q`（引语）／`FIG 文件 | 图注`。
- `make_combined.py` —— 总封面 ＋ 散文（罗马页码 i—xxvi）＋ 粗码（去掉原封面，阿拉伯页码不动）。

## 合一版的体例（重要）

散文用 **罗马页码 i—xxvi**，粗码保持**原阿拉伯页码**。这是唯一不用重算的做法：
粗码的目录、索引、节号、表图号、144 条书签全部锚在阿拉伯页码上，
一旦整体偏移，就要重做两遍回填 ＋ 索引 ＋ 书签。

代价是一处小别扭：粗码的扉页上印着「2」（它自己的第 2 页），而物理位置是全书第 28 页。
这是能接受的——两段页码各自自洽。

## 《中道周行集》这一版

每体独占一页，九页：封面｜题解＋总论序｜诗｜词｜散｜骈｜赋｜铭｜跋。

**律上调过的七处**（字句可对，只动不合律／蹈袭／自相矛盾处）：

| 体 | 旧 | 新 | 理由 |
|---|---|---|---|
| 诗 | 亢龙非力尽，知进不知退 | 悔在不知几 | 「退」出韵；「知几」用《易·系辞》 |
| 诗 | 日新周复始 | 日新无已时 | 「始」与「慎终以如始」重韵 |
| 诗 | （原结尾） | 大道本平易，而人好径歧。／谁谓中道远，日用而不知。 | 《老子》「大道甚夷而民好径」＋《中庸》「日用而不知」 |
| 词 | 贺太平 | 贺太和 | 《破阵子》一韵到底，「平」庚韵出韵 |
| 词 | 再着鞭 | 再淬磨 | 「鞭」先韵出韵 |
| 词 | 中流自在行 | 中流自在歌 | 「行」庚韵出韵 |
| 赋 | 海内一兮称盛 | 海内一统而称盛 | 缺字读不通 |
| 赋 | 聊乘化以归尽兮 | 聊乘化以周行兮 | 直抄《归去来兮辞》；「归尽」与「周行」正相反 |

没动的：「龙蛇随屈伸」（末字宜仄，改哪个都不如原句顺）、「松柏耐霜迟」（义稍涩）。
