# 行文规范 v1（2026-11-12）：把"框架感"换成"推进感"

> 适用：九本书 + 十五篇论文。与 `skeleton.md`（结构）并列：skeleton 管**长什么样**，本文件管**读起来有没有劲**。
> 原则只有一句：**每一节都要把事情往前推一步，而不是换一种说法重述同一个位置。**

## 0 诊断：读者说的"蒙着一层雾"是哪四种雾

| 雾 | 症状 | 例子（改前） |
|---|---|---|
| **元话语雾** | 先说"本章要证明…""本章路线是…"，把要做的动作说一遍，再做一遍 | "本章要证明一件事：'聊着聊着就忘了目标'不是健忘，而是状态在容量压力下的缓慢偏移。" |
| **抽象雾** | 变量摆出来（r、ε̄、nc），从不代入数字，读者不知道它有多大、发生在第几轮 | "nc≈(r/ε̄)² 这个平方项是关键。" |
| **对冲雾** | 每段结尾都加一句"但要注意/这只是假设/不能过度推广"，密度过高，读者失去落点 | 一段里三个"需要强调" |
| **无升级雾** | 每节从零开始介绍，读者读完第五节不知道比第一节多了什么 | 四阶段、三来源、四个预言……并列陈列，彼此不推进 |

**四雾同源**：都在描述"这本书长什么样"，而不是"这件事发生了什么"。

## 1 处方：六条硬规则

1. **每节至少一个可感物**：一个数、一个具体场景、一段真实的日志/表格。没有具象的节不许超过 600 字。
2. **每章一条主线**，用一句话写出来，然后每一节回答主线的下一问。主线不许是"多角度分析"。
3. **数字必须落地**：凡是给出关系式，**至少代一次具体的数**，并标明"示意"（不是测量）。
4. **每章至少一次反转**：一个反直觉的、能让人"哦"一声的观察（例：漂移的第四阶段，目标权重从 0.43 反弹到 0.88——**不是变弱，是换了目标且更自信**）。
5. **每个主张配一句"如果它错了会看到什么"**：可测、互斥、短。这一句比一段"局限性讨论"有力。
6. **删掉 2/3 的元话语**：保留一次路线图（在章首），其余全部改成"事实句"。

## 2 章内节奏（模板，六拍）

```
场景（1 段，具体的人与事）
→ 数字（1 段，把量级亮出来，读者立刻知道"这有多大事"）
→ 机制（形式化 1—2 式，随后立刻代入数字）
→ 三条独立线索（各 1 段，必须有非本书来源）
→ 反转（1 段，反直觉处，通常是"看起来 A，其实是 B"）
→ 代价与判据（谁在承担 + 如果错了会看到什么）
```

八段骨架（主提问 → 场景 → 导论 → 机制 → 表/图 → 反例 → 小结 → 一句话）**不变**，本模板只规定每段内部的密度。

## 3 与纪律的兼容（不可让）

- 数字：实测标"实测"，设定标"示意"，外推标"外推"。**三种不许混写。**
- 分级：每个可检验主张仍要带 A/B/C 与甲/乙/丙；节奏感不能换成确定性。
- 禁词：必然／注定／不可避免／无法消除／死路——升级感靠"数量级差"，不靠宿命化。
- 引用：外部进展只写"它证了什么、没证什么、本书为什么只用它做旁证"。

- [ ] 每节有至少一个数／物／例？
- [ ] 每个关系式代过一次数，并标了"示意"？
- [ ] 有一处真正的反转？（不是"但是也要注意"）

## 6 从《错位的时间》学到的七条（实测对比，2026-11-12）

《错位的时间》是作者投入最多的一本，也是全系列"最好读"的一本。把它和其他八本放在同一张表上，差距是**可测的**：

| 指标 | 错位的时间 | 其余八本的范围 |
|---|---:|---|
| 数字密度（数字/千汉字） | **78.8** | 24.6（只能选两样）— 76.7（区分的语言） |
| 表／章 | **4.9** | 0.9 — 4.7 |
| 节／章 | **7.1**（最少） | 6.8 — 16.6（涌现的临界） |
| 字／节 | **787**（最长） | 215（涌现）— 798（心灵的分岔） |
| 「数据来源」出现次数 | **59** | 0 — 5 |
| 「〔技术〕」双路径标记 | **25 章各 1 处** | 0 — 1 |
| 「可复现」 | **35** | 3 — 18 |
| 「核心结论」前置 | 7 | 0 — 2 |

七条经验，按可迁移性排序：

1. **每个数字背后有一句话的出处。** 不是"数据来源：见附录"，而是"世界银行 WDI，SI.POV.GINI，1963—2024，A 级"。读者能顺着这句话去查。
2. **节少而长。** 7.1 节/章、787 字/节——每节够写一个完整的论证，不必把一句话撑成一节。（对照：涌现的临界 16.6 节/章、215 字/节。）
3. **问题作标题。** 25 章里有 20 个"为什么…"式小节标题：读者带着问题进来，答案在节末。
4. **双路径。** 每章开头标一次〔技术〕，指明"从这里起可以跳过"；快速读者与专业读者各走一条路，不必互相将就。
5. **表多而不滥。** 4.9 表/章，且每张表都有"性质／注释"两行——性质说这张表是什么，注释说它不能用来干什么。
6. **结论前置且可核。** 关键节开头给"核心结论：…"，后面才是论证；读者可以先拿走结论，再决定读不读推导。
7. **可复现是承诺，不是形容词。** 35 处"可复现"都指到脚本或数据文件，没有一处是空口。

**反向清单**（其余八本最缺的）：数据来源（capacity 84 条表注里只有 5 条写了来源）、双路径标记（capacity 3 处、其余 0）、问题式标题（capacity 9 个、错位的时间 20 个）。
