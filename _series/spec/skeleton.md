## 0. 五条目的（写作前默读一遍）

1. **论证严谨**：每个断言有依据，每个依据有等级（A/B/C），每个等级有边界。
2. **逻辑清晰**：一章只回答一个主提问；一部分只推进一个转折。
3. **叙事完整**：有开头（谁遇到了什么）、有中段（试错与机制）、有结尾（让出了什么）。
4. **人文关怀**：写制度也写人；写约束也写承担者；**冷峻的验证，温暖的关怀**。
5. **生动有趣**：每章至少一个具体场景、一个具体人、一句能被记住的话。

**禁止**：重复（同义段落、同形章节）、颠倒（结语在正文前、回顾在中段、核心在案例后）。

## 1. 书：五段骨架

```
封面 → 书名页 → 版权页
前置 6 件（固定顺序、固定文件名）
  front_epigraph.html    题记（≤300 字）
  front_preface.html     前言：为什么写，让出了什么
  front_quickstart.html  速读：四种读者四条路
  front_terms.html       术语与符号（表；首次定义指向章号）
  front_roadmap.html     路线图（一张图 + 一段话）
  front_hardcore.html    （选）硬核入口：可跳过 / 不可跳过
主体 5–7 部分 × 3–6 章（共 22–28 章）
  每部分：part-title → part-intro（300–500 字）→ 各章 → part-summary（150–300 字）
后置 4 件
  back_epilogue.html     结语（只许有一个）
  back_popular_guide.html 通俗导读（四种读者）
  back_postscript.html   后记与致谢
  back_series.html       系列互引页（计数由脚本注入）
附录 ≤6（A–F，顺序固定）
  A 形式化与证明   B 数据与复现   C 稳健性与敏感性
  D 可证伪登记簿   E 工具、清单与模板   F 证据与数据缺口
参考文献（独立成件，不进附录序列）
```

**部分导语写什么**（这是"部分划分清晰"的全部技术含量）：

> 上一部分解决了 X。它留下一个未答的问题 Y。这一部分的 N 章按 A→B→C 推进，到部分末你会拿到 Z。
> 这一部分**让出**的是 W（一个被放弃的强主张、一个不做的承诺）。

**部分小结写什么**：三句话——本部分最硬的一条结论（带等级）；它依赖哪个未检验的假设；下一部分为什么必须从它开始。

## 3. 论文：十二至十六节

```
摘要（≤600 字：问题／做法／≤6 条数字／自我打击）→ Abstract
1  引言：问题 + 为什么现在回答得了 + 本文不做什么
2  框架/判据：把大词降到可测档；一句"本文档位：比喻/类比/机制/读数"
3  数据与方法：来源、口径、快照日期、复算路径
[实证档] 4 协议（预注册：否证条件写死数字）
4–9  结果 ×n：一条一节（叙述 → 表 → 量级 → 反例）
10 编码/探针（四问编码、断裂探针一类）
11 与六核心的接口（一张表，标"借用/修正/类比"）
12 自证（把方法用在自己身上；必须含对自己不利的一条）
13 讨论与边界（三条自我打击 + 三条不能说的话）
14 结论
参考文献
附录 ≤6（同书 A–F）
```

**档位**：`实证档` = 有实验或大规模计数，插第 4 节"协议"与第 10 节"逐条裁决"；`方法档` = 编码/审计/对账，无协议节。

## 4. 附录预算（书与论文同一套）

| 规则 | 阈值 | 判定 |
|---|---|---|
| 附录件数 | ≤6 | 数 `appendix*` / `^## 附录` |
| **附录单节长度** | **≤1200 字正文** | 逐节测；超长即"附录变成第二正文" |
| 参考文献、术语表 | 不得编进附录序列 | 标题 |
| 编号形态 | 只许 A–F；禁 `A0`、`D2–D9`、`J2`、`AA` | 正则 |
| 十个常见反对 | 并入讨论（正文节），不留独立附录 | 标题 |
| 图表索引 | 删除（PDF 书签已有） | 标题 |
| 术语英译 | 并入系列术语表，不逐本重复 | 标题 |
| 可证伪登记簿 | **必须保留**（append-only 证据） | 标题 |

> **为什么不用"附录占正文 ≤12%"**：全系列 1300 余个附录小节里，正文超过 1200 字的只有 **8 个**；
> 绝大多数是登记项、空白表、短条目与清单。按"字数占比"判，等于把一沓表格误判成"第二正文"——
> 实测中有 11 件因此被判"超标"，而它们单节最长不过 900 字。判据改为**逐节测长**后，
> 真正需要处理的只有 8 节（错位 2、分岔 2、四篇论文各 1），处理方式是把那一节搬进相关章，而不是搬家整本附录。

**准入判据**：一份材料配进附录，当且仅当它满足三者之一——**算得出来**（可复算）、**查得到**（可回溯来源）、**可被否证**（登记簿）。其余一律进正文。

## 5. 编号与命名纪律

1. 一个序列一个词：`卷第N`／`第N部分`／`第N章`／`N.M 节`／`表N.M`／`图N.M`／`式(N.M)`／`附录A`。**禁止**用"部"指章、用"附录C"指参考文献。
2. **冻结规则**：已发布的章号、节号、附录号，只在"重排窗口"内整体改动；窗口外不许增量改号。
3. **系列计数单一来源**：`inventory.tsv`。正文里指"写作时的前 N 本"必须写"**其时的 N 本**"。
4. **标题去重**：系列内不得有两件以上共享同一关键词作标题（现存"账单"三撞，论文九改名）。
5. **产物文件名不带件数**：`00-合集-印刷版.pdf`。
6. **附录文件名语义化**：`appendix_a_math / _b_data / _c_robust / _d_ledger / _e_toolkit / _f_gaps`；禁 `_x_restored`。

## 7. 语域（不是禁欲，是分寸）

- **张力，不宿命**：约束是交易的条件，不是判决。禁词：必然／注定／不可避免／无法消除／死路。
- **分级在装置，不在每句**：等级进表与附录；正文一句精确限定即可，不堆免责声明。
- **反例进正文**；**地图只定性**；**负面结果照实写**。
- **冷峻的验证**：数据的口径、快照日期、失败的那一次，都写出来。
- **温暖的关怀**：每个约束章必须指出"谁在承担代价"与"这条限制使什么成为可能"。
