## 31 一页判定卡（可打印）

**判断一个系统是否"容量受限"：四条中至少两条成立。**

| 编号 | 判据 | 怎么看出来 | 成立请打 ✓ |
|---|---|---|---|
| R1 | 槽位饱和 | 单位负载带来的槽位增量趋零，而负载仍在增长 | |
| R2 | 干扰 | 新增条目使旧条目的检索准确率下降 | |
| R3 | 分层消失 | 遗忘从"淡出"变成"整段断裂" | |
| R4 | 可复算 | 别人能用你给的表重算出 R1–R2 | |

**三条使用纪律**

1. **不排名**：只输出"受限／不受限"，不输出分数。
2. **不填满**：两格成立即可判定，其余留白是正常的。
3. **不跨层**：计数必须在同一层级上做，跨层混合会翻转结论（见第 8 章的失败重编码）。

**答不出来的三条**

- 如果 R4 答不出来，前面三条都不算数；
- 如果四条都"不确定"，说明这个系统还没有被描述过，先做描述；
- 如果只想问"容量有多大"，请回到第 10 章：本文没有回答那个问题，只回答了"装不装得下"。
