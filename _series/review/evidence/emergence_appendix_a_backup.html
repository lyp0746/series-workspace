附录 J　案例库：十个短案例

每个案例只给三样：什么在变、有没有临界点、判定。用来练手。

  1. 水沸腾：什么在变——气泡密度；临界点——100°C；判定：严格相变（一阶）。
  2. 磁体退磁：什么在变——净磁化；临界点——居里温度；判定：严格相变（二阶）。
  3. 图的连通：什么在变——最大连通块占比；临界点——β₁、β₂；判定：严格相变。
  4. 学习高原：什么在变——巩固速度；临界点——容量饱和；判定：可能是相变。
  5. 公司垮掉：什么在变——可持续性；临界点——不明确；判定：渐进退化（不是相变）。
  6. 疫情拐点：什么在变——R_t；临界点——R_t=1；判定：诊断级。
  7. 金融危机：什么在变——杠杆/利差；临界点——不明确；判定：诊断级（慢化明显）。
  8. 技术引爆点：什么在变——采用率；临界点——事后叙事；判定：隐喻级。
  9. 社会极化：什么在变——极化指数；临界点——不明确；判定：隐喻级（不可通约）。
  10. 历史范式转移：什么在变——学派分化；临界点——无法定位；判定：隐喻级。

练习： 挑一个你熟悉的系统，填这三样。填不出来，就说明它还不是“相变诊断”，只是“变化描述”。

附录 K　失败案例集：五个“看起来像，其实不是”

  1. 两杯水混合：有变化，无临界点、无序参量——不是相变。
  2. 利润由正转负：变号不是跃变——不是相变。
  3. 换工作：重要事件，但不是结构性转变——不是相变。
  4. 人口缓慢老龄化：连续趋势，无阈值——不是相变（除非跨过制度阈值）。
  5. 一次突发的外部冲击：恢复变慢是外力所致，不是临界慢化——不能算相变。

这五个案例的作用： 让你在“想叫它质变”时，先停一下。

附录 L　一次完整诊断的十步协议

```

  1. 写下“什么在变”（候选序参量）。
  2. 写下“它在哪个参数上变”（候选临界点）。
  3. 判断：一阶（跳）还是二阶（连续）。
  4. 找“变之前是否变慢”（临界慢化）。
  5. 找“宏观是否更好用”（有效信息峰值）。
  6. 数一数：三个标记中了几个。
  7. 若中两个以上：写下“什么结果会推翻这个判定”。
  8. 若只中一个：改称“像”，不称“是”。
  9. 若一个都不中：改称“退化/波动”。
  10. 标注证据等级与可反驳条件。

```

这十步，就是本书全部方法的“压缩版”。

附录 M　相变概念小史

  • 1930s：埃伦费斯特给出相变分类（一阶/二阶）。
  • 1937：朗道引入序参量，用对称破缺描述相变。
  • 1971：威尔逊的重整化群，解释“普适类”。
  • 1970s—80s：临界现象成为物理学中心问题；临界慢化、标度律被系统研究。
  • 1980s：混沌与分岔进入公众视野；“蝴蝶效应”流行。
  • 1990s：复杂性科学兴起；涌现成为跨学科词。
  • 2000s：网络科学；幂律与无标度。
  • 2010s：因果涌现、有效信息；涌现开始被“量化”。

这条小史说明： “相变”不是新词，但“把它用到社会/历史”仍是新事。

E1：棋盘式 Metropolis 的一次 sweep。

``python def sweep(s, T, rng): L = s.shape[0]; idx = np.arange(L) for color in (0, 1): # 棋盘式：同色格点互不影响 mask = ((idx[:, None] + idx[None, :]) % 2) == color nb = (np.roll(s, 1, 0) + np.roll(s, -1, 0) + np.roll(s, 1, 1) + np.roll(s, -1, 1)) dE = 2.0 * s * nb acc = (dE <= 0) | (rng.random(s.shape) < np.exp(-np.maximum(dE, 0) / T)) s[mask & acc] *= -1 ``

E2：集合式（ensemble）分支过程——为什么它快。

``python size = np.zeros(n); frontier = np.ones(n); active = frontier > 0 while active.any(): # 一次推进全部雪崩 size[active] += frontier[active] frontier[active] = rng.poisson(m * frontier[active]) frontier[size >= cutoff] = 0 active = frontier > 0 ``

关键点： 逐个体循环的复杂度是 O(总后代数)（可达 10⁶/次），集合式的复杂度是 O(最大代数)（约 10²），两者相差四到五个数量级。这是“把算法想清楚”比“换更快的机器”更有效的例子。

E3：对数分箱的正确拟合（这里最容易错）。

``python edges = np.geomspace(lo, hi, bins) h, _ = np.histogram(x, bins=edges) dens = h / np.diff(edges) # 必须除以箱宽 centers = np.sqrt(edges[:-1] * edges[1:]) alpha = -np.polyfit(np.log(centers), np.log(dens), 1)[0] ``

为什么必须除箱宽： 对数箱的宽度正比于 s，若直接用计数拟合，会把 n(s)∝s^{−1.5} 读成 s^{−0.5}。本书第一版就是这么错的（见 R.4 第 5 条）。

X.1　第二十五章　推导与解析（一）：朗道理论、临界指数与标度关系

前面讲“序参量”“临界指数”，但没推导。这一章补上：从自由能出发，推出临界指数与标度关系。

25.1　朗道自由能

设序参量为 η，外场为 h。把自由能按 η 展开（对称性要求只含偶次项）：

`` F(η) = F₀ + a η² + b η⁴ − h η ``

其中 a = a₀(T − T_c)，b > 0。

为什么只含偶次项？ 因为 η → −η 是对称的（例如磁化方向翻转，能量不变）。这一条对称性，决定了临界指数的“普适”。

25.2　平衡态：对 η 求极小

`` ∂F/∂η = 2aη + 4bη³ − h = 0 ``

情形一：h=0。

  • T > T_c（a>0）：唯一极小在 η=0；
  • T < T_c（a<0）：η=0 变成极大，极小在 η² = −a/(2b)。

于是：

`` η = ± sqrt( a₀(T_c − T) / (2b) ) ∝ (T_c − T)^{1/2} ``

所以 β = 1/2。 这是平均场的第一条指数。

25.3　磁化率：对 h 求导

在 T > T_c、h→0 时，η ≈ h/(2a)，于是：

`` χ = ∂η/∂h = 1/(2a) ∝ (T − T_c)^{−1} ``

所以 γ = 1。

25.4　比热：对温度求二阶导

F 在 T_c 处有一个“折点”，比热 C = −T ∂²F/∂T² 出现有限跳变，而不是发散。

所以 α = 0（平均场）。

25.5　关联长度

在平均场里，关联函数 G(r) ∝ e^{−r/ξ}/r，而 ξ ∝ |T − T_c|^{−1/2}。

所以 ν = 1/2。

25.6　标度关系：指数之间不是独立的

临界指数不是“六个独立的数”，它们满足标度关系：

`` Rushbrooke: α + 2β + γ = 2 Widom: γ = β(δ − 1) Josephson: ν d = 2 − α Fisher: γ = ν(2 − η) ``

这些关系，把六个指数压缩成两个独立指数。 这就是“普适类”的数学基础。

25.8　这对本书的意义

本书的“普适类”不是空话：它有一套可推导的指数与标度关系。 但本书也承认：社会/历史系统，几乎不可能测出这些指数。 所以，本书只借“结构”，不借“数值”。

25.9　朗道理论的局限

朗道理论是“平均场”：它假设 η 在空间均匀。这忽略了涨落。

什么时候涨落可以忽略？ 当维度 d 大于“上临界维度” d_c 时。对标准相变，d_c=4。

为什么？ 用“金兹堡判据”：涨落在关联体积 ξ^d 内的方差，要小于 η 的均值。当 d>4，这个条件满足；当 d<4，涨落改写指数。

所以，朗道的指数（β=1/2 等）只在 d≥4 严格。 二维、三维的伊辛，指数不同——这就是“平均场失效”。

25.10　一阶相变的朗道描述

如果 b<0，自由能 F = aη² + bη⁴ + cη⁶（c>0），会出现“双阱”。

当 a 从正变负，两个极小“交换高度”——在某个 a_c，η=0 与 η≠0 的极小等高。这就是一阶相变：序参量跳变。

一阶相变的标志： 潜热、滞后、两相共存。

25.11　三临界点

如果 b 也随参数变化，在 b=0 处，系统从“二阶”变成“一阶”——这个点叫“三临界点”（tricritical point）。

它的意义： 它说明“相变的类型”本身，也可以随参数改变。“二阶”不是绝对的，它可以是“一阶”的边界。

25.12　朗道与本书

本书借“序参量”“对称破缺”“临界指数”，但不借“平均场”的强假设。原因：社会/历史系统，既没有“空间均匀性”，也没有“可测的涨落”。

所以，本书只借“骨架”，不借“血肉”。 这是“借用工具，不冒充理论”的又一处。

X.2　第二十七章　推导与解析（三）：图拉普拉斯、渗流与复杂网络

这一章给“图上的相变”一套完整推导：从拉普拉斯谱，到两阶段相变，再到渗流与网络。

27.1　图拉普拉斯

设图 G=(V,E)，度矩阵 D，邻接矩阵 A。拉普拉斯：

`` L = D − A ``

二次型：

`` xᵀLx = Σ_{(u,v)∈E} (x_u − x_v)² ``

它衡量“x 在边上有多不平”。 x 越平滑，xᵀLx 越小。

27.2　谱与连通性

L 是实对称半正定，谱 0=λ₁ ≤ λ₂ ≤ … ≤ λₙ。

  • λ₁=0 对应常数向量（全图一致）；
  • λ₂（Fiedler 值）衡量“图有多容易裂成两半”：λ₂ 越小，越容易裂。

这就是“谱决定连通性”的数学版本。

27.3　线性动力学：临界耦合

设区分强度 D 满足：

`` Ḋ = (−αI + βL) D ``

按特征向量展开，第 k 个模式的增长率是 −α + βλ_k。

临界条件： −α + βλ_k = 0，即 β = α/λ_k。

  • 最大的 λₙ 对应“最高频、最局部”的模式，临界 β₁ = α/λₙ；
  • 次小的 λ₂ 对应“最全局”的模式，临界 β₂ = α/λ₂。

因为 λ₂ ≤ λₙ，所以 β₁ ≤ β₂——局部先解锁，全局后解锁。 这就是“两阶段相变”的全部推导。

27.5　渗流：另一种“图上的相变”

模型。 每条边以概率 p 保留，问“是否存在一个无限大连通块”。

临界概率。 二维方格：p_c ≈ 0.593（座渗流）、p_c = 0.5（边渗流）。

临界行为。 在 p_c 附近：

`` P_∞ ∝ (p − p_c)^β, β = 5/36 ≈ 0.139（2D） ``

集团分布： n_s ∝ s^{−τ} exp(−s/s*)，2D 的 τ = 187/91 ≈ 2.055。

分形维数： 在 p_c，最大集团 ∝ N^{d_f/d}，2D 的 d_f = 91/48 ≈ 1.896。

渗流是“最干净的相变样本”之一： 它有精确的临界概率、临界指数、分形维数。

27.6　复杂网络上的渗流

随机图。 G(N,p)，平均度 ⟨k⟩。临界点 p_c = 1/⟨k⟩。

一般网络。 用“分支因子” κ = ⟨k²⟩/⟨k⟩，临界点 p_c = 1/(κ−1)。

无标度网络。 若度分布 P(k) ∝ k^{−γ}：

  • γ > 3：⟨k²⟩ 有限，p_c > 0；
  • 2 < γ ≤ 3：⟨k²⟩ 发散，p_c → 0。

这意味着： 无标度网络对“随机故障”极其鲁棒（p_c→0），但对“针对性攻击”极其脆弱（攻击枢纽节点）。

这就是“鲁棒却脆弱”的数学版本。

27.7　这对本书的意义

这是全书唯一“可以完全算出来”的部分。 它说明：“相变”不是比喻，而是可以从谱、从概率、从网络结构推出来的。

但它也说明： 一旦离开“图”这个对象，推导就变得困难。这正是“形式化地平线”的数学根源。

27.8　Fiedler 值的界

λ₂ 与“图的连通性”有严格的界：

`` λ₂ ≤ (n/(n−1)) · min_{v} deg(v) ``

它说明： 度数越小的节点，越限制“全局连通”。这就是“瓶颈”的谱版本。

另一个界： λ₂ ≤ 2 · edge_connectivity / n。边连通性越小，λ₂ 越小，越容易裂。

27.9　谱与随机游走

在图上做随机游走，转移矩阵 P = D^{−1}A。它的特征值与拉普拉斯谱直接相关：

`` μ_k = 1 − λ_k / d （对 d-正则图） ``

混合时间（走到稳态的时间）由 1/(1−μ₂) = d/λ₂ 决定。λ₂ 越小，混合越慢。

这给“慢化”一个图论版本： 图越“接近分裂”，随机游走越慢——“临界慢化”在图上的对应。

27.10　网络渗流的严格条件

对配置模型（给定度分布），渗流阈值：

`` p_c = 1 / (κ − 1), κ = ⟨k²⟩ / ⟨k⟩ ``

推导要点： 从“一个节点出发，沿边能到达的节点数”的分支过程，临界条件是“分支因子 = 1”。

  • 若 κ>2：p_c>0，有“有限阈值”；
  • 若 κ≤2：p_c=0，任意小的 p 都能连通。

无标度网络 P(k)∝k^{−γ}： γ≤3 时 ⟨k²⟩ 发散，κ→∞，p_c→0。这就是“鲁棒却脆弱”的严格版本。

27.11　与本书两阶段相变的关系

本书的“两阶段相变”（β₁=α/λₙ、β₂=α/λ₂）是“线性动力学”的结果；渗流是“随机连通”的结果。

两者不同： 前者是“确定性的模式解锁”，后者是“随机的集团生长”。

但它们共享一个结构： 都是“图上的阈值现象”——跨过某个 p 或 β，全局性质改变。

这正是“同约束而不同构”的例子： 同一张图，两种机制，两种相变。

X.3　第二十九章　推导与解析（四）：有限尺度标度与临界指数的估计

理论给了临界指数，但"怎么从数据里把它估出来"？这一章讲有限尺度标度——这是把"相变"从"概念"变成"可测量"的关键技术。

29.1　为什么需要有限尺度标度

在无限系统里，关联长度 ξ 在临界点发散。但任何真实系统都是有限大小 L。

有限大小会"抹平"临界点： ξ 最多长到 L，所以临界行为被"圆滑"了。你直接测，永远测不到"尖锐的奇点"。

解决办法： 用不同 L 的数据，做"标度坍缩"。

29.2　标度假设

设某个可观测量 A（如磁化、序参量）满足：

`` A(L, T) = L^{ω/ν} · f( L^{1/ν} (T − T_c) ) ``

其中 ν 是关联长度指数，ω 是 A 的标度维数，f 是标度函数。

这个假设的意思是： 不同 L 的曲线，只要按 L 重新标度，就会"坍缩"到同一条 f 上。

29.3　数据坍缩：三步

第一步：固定 T_c 与 ν 的猜测值。

第二步：把每个 L 的数据，画成 L^{−ω/ν} A 对 L^{1/ν}(T−T_c)。

第三步：调 T_c、ν、ω，直到所有曲线"叠成一条"。

叠得越好，参数越可信。 这就是"用数据估临界指数"的标准做法。

29.4　Binder 累积量：更稳的 T_c 估计

`` U = 1 − ⟨m⁴⟩ / (3⟨m²⟩²) ``

为什么用它？ 因为不同 L 的 U 曲线，在 T_c 处相交。交点就是 T_c，而且它不依赖 ω。

这是"最稳"的 T_c 估计法之一。

29.5　一个可复算的例子

以二维伊辛为例（T_c≈2.269）：

  • 取 L=16, 32, 64, 128；
  • 每个 L 跑 Monte Carlo，测 m、χ、U；
  • 画 U 对 T，找交点 → T_c；
  • 画 m L^{β/ν} 对 L^{1/ν}(T−T_c)，调 β/ν、ν 直到坍缩；
  • 得到 β≈0.125、ν≈1。

这与 Onsager 的精确解一致。 这就是"数值验证理论"的完整流程。

29.6　这对本书的意义

它说明"临界指数"不是"哲学词"，而是"可以估出来的数"。 但本书也承认：这套方法需要"可重复的实验/模拟"与"大样本"。

社会/历史系统，两条都不满足。 所以，本书只能借"标度"的思想（不同尺度要一起看），不能借"标度坍缩"的技术。

29.7　一句话带走

临界指数之所以可信，不是因为它"推导得漂亮"，而是因为它"能被数据坍缩估出来"。

X.4　第三十章　边界（二）：约束、可行域与 KKT

第二十八章讲"边界决定性质"的直觉。这一章把它形式化：约束优化、可行域、KKT 条件——这是"边际"与"边界"的数学骨架。

30.1　约束优化

`` max f(x) s.t. g_i(x) ≤ 0, h_j(x) = 0 ``

可行域 𝔽 = {x : g_i(x)≤0, h_j(x)=0}。最优解可能在"内部"，也可能在"边界"。

30.2　拉格朗日乘子

对等式约束 h(x)=0，构造：

`` L = f(x) − λ h(x) ``

一阶条件：∇f = λ ∇h。几何意义：在最优解处，目标函数的梯度，与约束曲面的法向平行。

λ 的经济意义：影子价格。 约束放松一单位，目标能增加 λ。

30.3　KKT 条件

对不等式约束，最优解满足：

`` ∇f = Σ μ_i ∇g_i + Σ λ_j ∇h_j μ_i ≥ 0, μ_i g_i = 0 g_i ≤ 0, h_j = 0 ``

关键是"互补松弛" μ_i g_i = 0：

  • 若约束不起作用（g_i<0），则 μ_i=0；
  • 若约束起作用（g_i=0，在边界上），则 μ_i≥0。

这就是"边界解"与"内点解"的数学区分： 内点解里，约束的"价格"为零；边界解里，约束有正价格。

30.4　与"边际"的关系

在经济学里：

  • ∇f 是"边际收益"；
  • ∇g 是"边际成本"；
  • λ、μ 是"边际约束的价格"。

所以，"边际分析"就是"在边界上做导数"。 不是在"总量"上做文章，而是在"再走一步"上做文章。

30.5　与 C-A-T 三角的关系

本书的 C-A-T 三角，本质上是一个可行域：

  • 三项预算 Σ ≤ K；
  • 三角的边界，就是"可行域的边界"；
  • "让出哪一个顶点"，就是"在边界的哪一段"。

"诊断"的动作，就是"找边界"：不是问"系统内部怎么运作"，而是问"它撞到了哪条边界"。

30.6　分岔：稳定性的边界

除了"约束边界"，还有"稳定性边界"。

设系统 ẋ = F(x, μ)。平衡点 x*(μ) 的稳定性，由 Jacobian J = ∂F/∂x 的特征值决定：

  • 所有特征值实部为负 → 稳定；
  • 有特征值实部为正 → 不稳定；
  • 特征值实部过零 → 分岔。

分岔点，就是"稳定性边界"。 越过它，系统的"质"就变了。

30.7　三种边界，一个结构

边界类型数学例子
约束边界KKT、可行域预算、产能、三角
稳定性边界特征值过零、分岔失稳、振荡、临界慢化
相边界自由能极小切换固/液/气、序参量跃变

三者都是"边界决定性质"的不同写法：

  • 约束边界决定"能做什么"；
  • 稳定性边界决定"稳不稳"；
  • 相边界决定"是什么相"。

30.8　一句话带走

"边际"是在边界上做导数，"分岔"是稳定性过零，"相变"是自由能极小切换——三者都是"边界决定性质"。

X.5　第二十八章　边界：为什么决定性质的是"边"，不是"里面"

前面讲"临界点"，但没讲"边界"这个更一般的概念。这一章把数学的边界条件、经济学的边际、物理化学生物的临界条件并排，看它们是不是同一件事。

28.1　数学：边界条件决定解

最干净的例子：拉普拉斯方程。

`` ∇²u = 0 （在区域 Ω 内） u = f （在边界 ∂Ω 上） ``

关键： 方程本身（∇²u=0）有无穷多解；是边界条件 u=f 把解“钉死”的。 换一个边界条件，就换一个解。

  • Dirichlet 条件：给定边界上的值；
  • Neumann 条件：给定边界上的法向导数；
  • 混合条件：两者都有。

这就是“边界决定性质”的最直接版本：内部方程相同，边界不同，解就不同。

更深一层：边界算子。 拓扑学里，一个区域 Ω 的边界记作 ∂Ω，而 ∂(∂Ω)=∅（边界的边界是空集）。这个“∂²=0”，是斯托克斯定理 ∫_Ω dω = ∫_{∂Ω} ω 的代数根源。 边界不是“附属品”，它是“内部”的对偶。

极限与奇点。 数学里还有一类“边界”：定义域的边界。函数在边界上可能连续、可能发散、可能不可导。很多“性质”只在边界上才显现（如 1/x 在 x=0 的奇点）。

28.2　经济学：边际是“增量的边界”

边际效用。 MU = dU/dx。“边际效用递减”（Gossen 第一定律）：随着消费增加，每多一单位带来的效用递减。

边际成本与收益。 利润最大化条件：MR = MC。不是“总收益最大”，而是“再走一步的收益 = 再走一步的成本”。

边际替代率。 MRS = MU_x / MU_y；它决定“无差异曲线”的斜率。

拉格朗日乘子。 约束优化 max f(x) s.t. g(x)=0，拉格朗日函数 L = f − λg。乘子 λ 是“影子价格”：约束放松一单位，目标能增加多少。

角点解与内点解。 最优解可能在“内部”（MR=MC），也可能在“边界”（如预算全花光、产量为零）。“边界解”是经济学里最容易被忽略、却最常见的情形。

边际与平均。 一个漂亮的结论：边际成本曲线穿过平均成本曲线的最低点。 因为“再走一步的成本”与“平均成本”的关系，决定了平均成本是升还是降。

28.3　物理：临界条件是“相边界”

相边界。 在 P-T 图上，固/液/气的分界线，就是“相边界”。跨过它，物质就换了相。

Clausius–Clapeyron 方程。 相边界斜率：

`` dP/dT = L / (T ΔV) ``

其中 L 是潜热，ΔV 是体积变化。它告诉你“边界往哪边走”。

成核的临界尺寸。 一个新相要长出来，需要克服表面能：

`` r* = 2γ / ΔG_v ``

r 的核会溶解，r>r* 的核会生长。“临界尺寸”就是“生与死”的边界。

活化能。 化学反应速率 k = A exp(−E_a/RT)。只有能量超过 E_a 的分子，才能越过“反应边界”。

28.4　化学：阈值与平衡

反应阈值。 很多反应需要“临界浓度”或“临界温度”才能启动。

平衡。 ΔG = 0 是“反应方向”的边界：ΔG<0 正向，ΔG>0 逆向。

催化。 催化剂不改变平衡，只降低“活化能”——它把“边界”挪低了，但没挪走。

28.5　生物：阈值与临界质量

神经元。 膜电位达到“阈值”（约 −55 mV），才触发动作电位。低于阈值，全是“局部电位”；越过阈值，才是“全或无”的脉冲。

种群。 Allee 效应：种群低于“临界规模”，增长率变负——太少，也会灭绝。

生态。 临界点（tipping point）：湖泊富营养化、珊瑚白化、森林退化，都有“越过就回不去”的阈值。

酶动力学。 Michaelis–Menten：v = V_max [S]/(K_m+[S])。它没有“阈值”，只有“饱和”——这提醒我们：不是所有“边界”都是“临界点”。

28.6　共同结构：为什么“边”决定“里”

把五个领域并排，会看到一个共同结构：

  1. 边界条件决定解（数学）：内部方程相同，边界不同，解不同；
  2. 边际决定决策（经济学）：不是“总量”，而是“再走一步的增量”；
  3. 临界条件决定相（物理化学生物）：跨过边界，就换规则。

三者其实是同一句话的三种说法：

一个系统的“性质”，往往不由“内部”决定，而由“它与外部的交界”决定。

为什么？ 因为“内部”是“被边界约束的解”；“边际”是“解的导数在边界上的值”；“临界”是“解在边界上的不连续”。

28.7　与本书的关系

  • C-A-T 三角：它是“可行域的边界”——不是“内部怎么走”，而是“边界在哪”。
  • τ：它是“时间的边界”——不是“系统有多强”，而是“还剩多少时间”。
  • 临界点：它是“相边界”——不是“相内怎么变”，而是“跨过去就换规则”。
  • 边际：它是“值的边界”——不是“总量多少”，而是“再多一单位值不值”。

所以，本书的“临界”只是“边界”的一个特例：边界是“相”的边界；边际是“值”的边界；可行域是“策略”的边界。

28.8　一句话带走

决定性质的，往往不是“里面有什么”，而是“边界在哪里、跨过去会发生什么”。
