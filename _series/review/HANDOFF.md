
八条硬约定（逐条核对）：

1. **图内不写标题**——标题由书稿的 `图 N.M　…` 题注承担（现状：多数图把标题画在 PNG 里，与题注重复）。
2. 最小字号 ≥ 7pt；中文用雅黑→黑体→Noto CJK 链。
3. **不重叠**：用 `constrained_layout`，不要手工 `tight_layout` 叠加；子图共享坐标轴。
4. 只用 PALETTE 八色；不上渐变、不上阴影、不做纯红/纯绿对比。
5. 网格 0.5pt 浅灰；只留左、下两条轴线。
6. 300 dpi、`bbox_inches="tight"`、白底。
7. 图例不压数据点；标注线要有引线（annotate 的 arrowprops）。
8. **每张图要能回答一个问题**：去掉标题后读者仍能看出"在比什么"。

执行顺序（每仓一遍）：先 `make_figures.py` 换 import → 跑 → 目检 3 张 → 全跑 → 重建论文 PDF（`analysis/assemble.py` + `generate_publication_suite.py`）→ 同步 CITATION/.zenodo 页数。
