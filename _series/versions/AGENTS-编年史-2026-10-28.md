**六篇共同的方法纪律**

1. **篇幅**：≥50 页；每轮用 `pypdf` 量页码（约 500—600 汉字/页）。加表、加附录优先于加字。
2. **对照表**：每篇必备，缺则不算完成。
3. **自证一章**：把自己的方法用在自己的方案上（第四篇第 5 章是范式；自评结果必须包括对自己不利的那一条）。
4. **判据演进**：评分 → 排除 → **必要条件**（第五、六篇）；必要条件只能被单例否定，不能由 p 值支持。
5. **日期**：`完成日期`／`publication_date`／`version` 用本次真实完成日；**数据快照日期不改**。
6. **发布**：旧论文出修订走 Zenodo **新版本**（`new_version.py` 或 newversion + resume），不新建记录；
   概念 DOI 不变，版本 DOI 变。上传会遇 504，需可重跑脚本；0 文件的空草稿要删除。
7. **写回**：发布后把版本 DOI 与概念 DOI 写回 `CITATION.cff` 与 `README`；正则批量改 DOI 会误伤正文里别的条目，改完必须 grep 校验。

## 0.5 第十三篇：锚点的下限（2026-10-26 归档，测试篇）

**《锚点的下限：情景记忆的模拟对照实验与 0.57 的覆盖率阈值》**（51 页；版本 DOI 10.5281/zenodo.23667929；概念 DOI 10.5281/zenodo.23667928）。
任务：执行论文十二附录 D 的替身实验。**机制模拟，非 LLM 实验**；5 页面 × 2 表面标签（负迁移陷阱）× 4 条件（M0/M1/M2/M2w）× 12000 步主对照、80000 步覆盖率扫描、81 组敏感性；**四条预注册否证条件**。

六条结果：
1. 主对照：准确率 M2 0.441 > M1 0.339 > M0 0.000；跨页面污染率 **0.625（摘要）/ 0.187（无记忆）/ 0.179（情景）**——**摘要是最危险的记忆**（无记忆的 3.3 倍）。
2. 但**误动作率 M2 0.209 未胜 M1 0.196** → **F1 部分触发**（本文最重要的一条自我打击）。
3. **覆盖率交叉点 0.569**（对种子自举 95% 区间 **0.44–0.74**）：低于它不如摘要，高于它才开始赢；换参数移动 ±0.10。
4. **允许回写（M2w）**：准确率 200 步内 0.338→0.151、误动作 0.209→0.273，而**人环反而下降**——污染让系统更自信。量化了「重建不得回写账本」。
5. ρ 0→0.7：误动作 0.092→0.118、人环 0.55→2.40；**K 的收益在 3 处饱和**（K=5 只再降 0.001，+554 ms）。
6. **p 三倍只让误动作 0.106→0.110；覆盖率 0.5→0.9 让它 0.210→0.080（32 倍）** → **补账本比换模型有效**。

十条命题：八支持、一未检验（T9 仍撤回）、一撤回（T10：0.57 不可迁移）。附「一次失败的 M1 设计」「一次参数误设的教训」「如果重做会改哪三处」与 ODD 九项自查。

**系列层面的结论（本轮新增）**：判据的演化再进一步——**评分 → 排除 → 必要条件 → 准入条件（阈值 + 区间）**。一条主张若说不出「在哪个参数区间成立」，它就不是可维护的主张。

## 0.6 第十四篇：开明君主与两层竞争（2026-10-27，测量篇）

**《开明君主与两层竞争：agent 价目表上的执行、方向与代价承担者》**（51 页）。起点是一段「人是不是 agent 的开明君主」的对话；本文把它压成三个价目表能回答的问题。四份公开快照（438 个模型目录、28 个端点读数、175 个许可证、九家一手价目页与平台周报，取数 2026-10-26／27）。

六条结果：
1. **重放—判断价差（RJS＝输出价 ÷ 缓存读价）** 294 个模型中位 **34.5 倍**；闭源 50、开放 19；官方价目页 12—200 倍，多托管市场把同一批模型摊平到 19 倍 → **重放被竞争压到底，判断由厂商定价**。
2. **「执行变便宜」是同名不同物**：按同能力算降约 150 倍（单源），按「当月新模型标价中位」算闭源 $6.00→$5.00、开放 $0.65→$0.60（不降）；且 Google 公告 Gemini 4 Argon 自 2026-12-01 起输出价 $10→$20。
3. **量与钱分离**：周 token 量 0.5 万亿→128.4 万亿（250 倍／20 个月），开放权重 62—79% token，闭源 73% 消费额。
4. **双层是常态**：6/9 家同时经营可自托管层与独占层，溢价 2.9—83 倍（中位 21.3）。
5. **席位不随执行降**：8 个公开价位 $12.6—$200；ChatGPT Plus 三年仍是 $20。
6. **低价的一半是数据**：首方最低价以训练权为对价，不训练托管约 2 倍价。

三条自我打击：**T8 被自己的数据否证**（溢价与 T 分无单调关系）；「假竞争」改判为**两层竞争**；「开明君主」只能是**比喻档**（断裂在复合层）。两处自我修正：T2（闭源价差高于开放）控制上下文长度后降为「部分」（ρ=0.53 的混淆，正文 4.7）；Gemini 涨价是公告而非已生效。

## 0.4 第十二篇：记忆的锚点（2026-10-26 归档）

2. **章节标题同规矩**：用「合集一览」而不是「二十三件一览」；后记不写件数。
3. **产物文件名不带件数**：`00-合集-印刷版.pdf`、`01-合集-电子版.pdf`、`02-合集.html`、`03-合集.md`、`04-assets.zip`。
4. 件数只允许出现在两处：版本记（写本次新增了什么）与清单表本身。

**排版三条硬规则（合集专用，踩过坑）**

1. **页尺寸**：用 Playwright `format="A4"/"B5"` + `prefer_css_page_size=True`；Chrome CLI 会退回 Letter。
2. **封面满版**：`@page { margin: 25mm 28mm }` + `.cover { width:210mm; height:297mm; margin:-25mm -28mm 0 -28mm }`；
   不要用 `@page :first`/具名页（在本机 Chromium 上不稳）。
3. **正文居中**：覆盖 `paper.css` 的 `max-width:145mm` 为 `none`，让正文填满 154mm 版心（左 28mm、右 ≈30mm）。

## 0.7 发布元数据的两套格式（2026-10-28 定，别搞错）

Zenodo 的 description 有两种写法，**按件的性质选，不按篇幅选**：

- **论文（工作论文/预印本，`publication_type: preprint`）用「论文格式」**：
  `<p><b>本版（YYYY-MM-DD，第 N 版，M 页）。</b>…` → `<p><b>本文做什么。</b>…` →
  `<p><b>Abstract.</b>…（英文）` → `<p><b>Files.</b>…` → `<p><b>系列 / Series。</b>…`。
  开头必须先是**版本行**，不要用「一句话。」「这是什么。」之类各自为政的开头。
- **书与合集（`publication_type: book`）用「书籍格式」**：
  `<p><b>中文。</b>…` → `<p><b>核心主张：</b>…` → `<p><b>结构与证据：</b>…` →
  `<p><b>本版修订（日期）。</b>…` → `<p><b>诚实纪律：</b>…` → `<p><b>边界：</b>…` →
  `<p><b>版本：</b>…` → `<p><b>系列 / Series。</b>…`。

标题一律 `中文题名：副题 / English Title: Subtitle`；`publication_date` 与 `version` 都用真实完成日（不带 v1／2.0）。

**每篇发布描述要备两份**（`_zenodo/desc_v3.py` 一次生成）：
- `_zenodo/desc/<slug>.html`——HTML 版，**只在编辑器切到源码／HTML 视图时粘贴**；
- `_zenodo/desc_plain/<slug>.txt`——纯文本版，**富文本模式下直接粘贴**（Zenodo 的富文本会把 HTML 转义成字面量，这是踩过的坑）。
纯文本用空行分段，不加 Markdown 记号（`**`、`#` 在富文本里同样不渲染）。

## 4. 写作风格（重要）

见 skill `academic-book-pipeline` 的 `references/voice.md`。要点：

- **张力，不宿命**：约束是交易的条件，不是判决。禁止把“必然／不可避免／无法消除／注定／死路”
  当作结论。每个硬约束章必须带反向力量：这条限制**使什么成为可能**。
- **分级在装置，不在每句**：证据/概念等级放表格与附录；正文一句一个精确限定即可，
  不反复“本书不宣称”，不堆叠免责声明，不表演式谦逊。
- **反例进正文**；**地图只定性**；**负面结果**照实写出。
- **结构由论证决定，不照搬模板**：部分与章节数由推理需要决定，并在前置部分说明为什么这一章
  接在上一章之后。

## 5. 研究哲学（系列立场，内化自讨论）

完整规范见 skill `academic-book-pipeline/references/research-philosophy.md`。要点：

- **开放式、贝叶斯、可证伪**。核心工作流：
  `观察 → 抽象 → 建模 → 现实应用 → 反馈 → 更新`。理论是持续演化的模型，不是最终真理；
  一切标记为“进行时”，`M_{t+1} = Update(M_t, E_t)`。
- **证据分级封顶结论**：`结论强度 ≤ 证据强度`。A 官方可复现 / B 稳定公开估计 / C 稀疏·构造·思辨。
- **假设—证据—状态—可证伪登记**是理论级版本控制，也是它的“长期记忆”；每本书都附登记表，
  记录证实/证伪、开放问题、**现实应用反馈**与**领域授权边界**（哪些由框架负责、哪些须交领域专家）。
- **最小验证**：不试图一次证明宏大体系，只找最小可验证单元（局部引理、极小反例、单点机制）。
- **能力阶梯**：描述 → 压缩 → 预测。多数跨域框架停在前两级，须如实标明；警惕
  **抽象速度超过验证速度**——找到跨域同构，不等于获得了新的预测能力。
- **边界意识，拒绝解释一切**：框架只提供分析坐标，不替代领域知识；气候、能源、教育、医疗、
  AI 治理等结论由该领域从业者验证与实施。框架提出者不拥有问题。
- **实事求是**：不伪造数据，承认失败，失败记录与成功同样有价值；“不是为了研究而研究”，
  理论的价值在于改善判断与行动。
- **元层次必须回到经验层**：自检四问——预测是否提高？模型是否压缩？决策是否改善？
  实验是否区分了竞争假设？

## 6. 传播与语言策略（内化自讨论）

完整规范见 skill `academic-book-pipeline/references/reach-and-language.md`。要点：

- **入口文档优先**：仓库首页 / 记录页先给 `摘要 → 一句话主张 → 核心公式 → 主要论断（带强度）
  → 框架 → 例证 → 边界 → 引用`，让陌生人五分钟内知道“这是什么、属于哪个领域”。
  醒目的书名（如“熵螺旋”）必须紧跟一句去歧义的定位句。
- **英文摘要 / 研究笔记，而非默认翻译全书**：20 多万字专著的全译是数月级专业工程，
  不默认承诺、不用机翻交付。优先做 **500–1000 词英文摘要**（写入元数据）+
  **5–10 页英文研究笔记**（核心公式、两个领域各一例、局限，附专著 DOI）。
  顺序是：**先有人读，再有人引用，最后才可能有人翻译**。
- **下载量要诚实地读**：Zenodo 的下载/浏览符合 COUNTER、过滤机器人，数字偏保守；
  没有官方均值。两天 0–5 正常、5–15 不错、15–30 很好、30+ 通常伴随宣传或热点。专著下载是
  长尾，真正要看 **7/30/90 天曲线**、Google Scholar/OpenAlex 收录、收藏（Zotero/Mendeley）
  与后续引用。早期小数字对“非机构、非本专业、跨学科”的作品反而更有意义。
  不夸大、不篡改、不挑拣指标；把传播数据当作一条观察，带日期记入研究日志。
