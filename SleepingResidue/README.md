# 线外的残余：被埋没的理论为何被重新发现，为何永久沉默

**二十四个延迟承认案例的三标记检验、两个必要条件与一份负面清单**

## 一句话

被埋没的是文献，起作用的是解码器：恢复组沉寂中位 **37.5 年**，而解码器出现到被承认的中位滞后是 **0 年、上限 5 年**；而三标记在这里不能当打分表——永久沉默的燃素说与热质说各命中 2 条，区分它们的是**必要条件**（解码器 18/18 对 0/6）。

## 五条主结果

1. **沉寂由解码器决定，不由文献决定。** 文献一直在架上；"想起来"的时刻由工具决定。
2. **旧坐标决定回归路径。** 不合法→范式更替；异常→新工具；被误解→重新命名；接收端成本→跨域连接；主动撤回→模型化。
3. **重发明只发生在可重建时。** 3/3 对 2/18（Fisher p=0.0075）。"翻译成本低于重新发明"应修正为**可重建性**。
4. **三标记是排除装置，不是打分表。** 解码器是必要条件（18/18 对 0/6）；而必要条件只能被反例否定，不能被 p 值支持。
5. **恢复是分层的。** 方法保留 17/18、作者保留 13/18、术语只保留 10/18。

## 三条负面清单

- 载体销毁（玛雅抄本）：残余不存在，框架失效。
- 残余被吸收（燃素说、热质说）：异常被解释，命题被丢弃。
- 目的论（"正确终将被想起"）：被明确拒绝；沉默只需要一个条件缺失，恢复需要三个条件同时具备。
