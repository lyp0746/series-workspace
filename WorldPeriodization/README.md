## 一句话

分期不是事实，是切线：46 部核心来源、195 条边界，加上 14 部前现代编年史、55 条边界；欧洲中心不体现在某一条线的有无，而体现在门的数量、位置与排他性——1500 仍在，但它在全球史里被孤立，在欧洲中心与中国教材里成组。

## 五个结果

1. **集中，但机制是复制。** 前十承担 69.7%（零模型 10.1%）；40 部世界／区域史只用 32 套顶层切线，模板级前十 75.0%（零模型 26.3%）。有效独立样本约 32，不是 46。
2. **三组传统的门不同。** 全球史 64% 含 1000—1225、71% 含 1750±15（欧洲中心 13%／7%）；中国教材 82% 含 1640、91% 含 1917（欧洲中心 0%／0%）；1500 三组共有（73%／71%／64%）。
3. **分区距离。** 组内 ARI 0.65 > 组间 0.51（p=0.0005），但传统只解释 29%；全窗上中国—欧洲（0.602）高于中国—全球（0.434），近代段反转（0.243 对 0.197）。相似主要来自 1500 年前"双方都不切"。
4. **交叉是恒等式。** 交叉曲线逐点等于各传统"已近代比例"的函数（R²=1.0000，残差 8.3×10⁻¹⁷）；它不构成独立证据，已降为派生展示。
5. **门的三个量。** 跨三组通用的门只有 1500 与 1914；1640、1917 是单传统门。1500 的出现率相近（73／71／64），排他性相反（0.40／1.00／0.14）。

## 扩展语料（W10）

14 部前现代与非欧洲编年史：伊斯兰 3、美洲 3、非洲 2、东亚 2、南亚 2、前现代欧洲 2。9 部印年、6 套纪年（公元、希吉拉、世界纪年、王朝纪年、Laukika、混用）；5 部只有时期名。核心语料的门在扩展语料中几乎不出现（只有 589 重合）。**边界年是现代教材体裁的变量，不是"分期"的普遍变量。**

## 边界

- 不评价哪个分期正确；只记录切线位置与门的结构。
- 核心语料不是抽样：46 部是"能查到的、有代表性的"集合；扩展语料是"能让测量失效的例子"。
- 编码依据目录与课程框架，未逐页核对正文；era、level、name_type 为判断字段。
- 单一编码者自曝：20% 复编由同一人盲态完成；扩展环无复编，等级 C。
- 维基只作补充；分区距离依赖窗口，全窗与近代段会翻转。
- 核心语料里非洲 0 条边界；扩展语料有非洲编年史，但它们不进世界史的门。
