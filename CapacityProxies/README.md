# 容量的三个代理：分期槽位、编码槽位与标签槽位

**一次用既有数据检验「容量保护记忆」的尝试，以及它的一半失败**

## 一句话

《遗忘的边界》的容量—压缩—遗忘有一个始终没补上的缺口：容量从未被测量。本文给容量找三个可数的代理——分期槽位、编码槽位、标签槽位，用三篇既有论文的原始数据检验「容量越大，忘得越少」。结果三种：分期槽位支持（分箱 0.50→0.14，r=−0.245）；编码槽位相反但不可判（r=−0.682，与撤县年数 r=−0.835 混淆）；标签槽位反向（r=+0.932，证伪「名额紧张导致质量稀释」）。冷结论：容量不是单向保护。
