## 一句话

「优化」听起来像方法，实际上是一个四前提结构：目标函数、搜索空间、预算与时钟、停止规则。缺任一项，优化就变成另一种东西——指标失真、锁定、无限投入或反噬。本文把优化安放在六核心之间：目标由「讲述」提供，空间由「看见」划定，预算由「记住」与「跟上」提供，停止由「临界」判定；因此优化不是第七个核心，而是横切四核心的「搜索—评估—停止」循环。本文编码 20 个越界案例：目标 7、空间 5、停止 5、预算 2，另加一个反例（进化）。结果：目标越界最普遍且多致指标失真；停止越界后果最重（4/5 为「重」）；预算越界最易被忽略，因为新建可计入政绩、维护不能。反例章说明进化没有目标函数与全局停止规则，只有局部搜索与压缩账单。
