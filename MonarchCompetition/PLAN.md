# 开明君主与两层竞争 — 论文计划（新会话从这里开始）

**题目**：开明君主与两层竞争：agent 价目表上的执行、方向与代价承担者
**英文**：The Enlightened Sovereign and Two-Tier Competition: Execution, Direction, and Who Pays on the Agent Price Sheet
**定位**：系列第十四篇（测量篇）。第十篇的 D21 领域补录 + 第十一篇的第四十一条声明 + 一个可复算的价格比指标（RJS）。

## 一句话主张

价目表把「执行」与「方向」分开定价：一次新判断比一次重放贵 34.5 倍（中位）；这个价差在多托管市场被压到 19 倍、在自家价目页上可到 200 倍。**重放被竞争压到底，判断由厂商自己写。** 九家里六家同时经营「可自托管层」与「独占层」，溢价 2.9—83 倍——竞争在商品层，收租在旗舰层。

## 已知空缺（写的时候不要隐瞒）

1. 单平台偏置：只有 API 聚合市场，无企业私有部署、无消费端使用（14.1）；
2. 全部为标价，不是实付价（14.2）；
3. 无能力分数，「同能力价格」只有单一来源一次估计（T3）；
4. 席位价只有一个时点，无法回答「席位价三年里变了吗」（T9 只能到 B）；
5. 一编码者，无第二编码者；
6. 「被替代者」完全没有测量，只有相对价格的结构关系（9.4）。
