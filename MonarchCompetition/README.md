# 开明君主与两层竞争：agent 价目表上的执行、方向与代价承担者

**九个实验室的双层价目、一个 34.5 倍的重放—判断价差，以及「开明君主」这一比喻的断裂探针**

李毅芃 · 2026-10-28 · 工作论文（51 页，CC BY 4.0）

*The Enlightened Sovereign and Two-Tier Competition: Execution, Direction, and Who Pays on the Agent Price Sheet*

## 一句话

「人是开明君主，agent 是臣民」这个说法有一半是对的：**执行权确实在扩散**（平台周 token 量 20 个月涨 250 倍，2026-02-06 之后 agent 用的 token 比人多）；但红利没有跟着扩散，因为**价目表只在一栏里竞争**——294 个模型的重放—判断价差（输出价 ÷ 缓存读价）中位 **34.5 倍**，闭源 **50 倍**、开放 **19 倍**（控制上下文长度后这一差只两档成立），而在自家价目页上 DeepSeek 与 Claude Fable 5.1 都把它定到 **200 倍**。九家里有六家同时卖「能搬走的一层」与「搬不走的一层」，两层价差 **2.9—83 倍**。竞争在商品层，收租在旗舰层。

## 摘要

数据是四份公开快照（2026-10-26／27）：438 个模型的价目与托管读数、九个实验室的一手价目与席位页、平台方每周发布的用量口径。四个结果。（1）RJS 中位 34.5 倍；官方价目 12—200 倍，多托管市场把同一批模型摊平到 19 倍——**重放被竞争压到底，判断由厂商定价**。（2）「执行变便宜」是同名不同物：按同能力算降了约 150 倍，按「当月新模型标价中位」算闭源只从 $6.00 降到 $5.00，且 Google 官方公告 Gemini 4 Argon 自 2026-12-01 起输出价 $10→$20。（3）量与钱分离：开放权重拿下 62—79% 的 token，闭源仍拿 **73%** 的消费额。（4）双层是常态：6/9 家，溢价中位 21.3 倍。

三条自我打击：T8（溢价与可传递性单调）被自己的数据**否证**（T=4 的 OpenAI 83.3 倍对 T=3 的 Kimi 2.9 倍）；「假竞争」这个词站不住，改判为**两层竞争**；「开明君主」放进四级强度阶梯只能到**比喻**档，断裂在复合层。另有两条对语料的自我修正：T2（闭源价差高于开放）在控制上下文长度后退化为「部分」（分档后只两档成立）；Gemini 涨价是**公告**而非已生效。

## 三条自限

1. **单平台偏置**：价目与托管读数来自一个 API 聚合平台，不含企业私有部署与消费端使用；偏差方向在正文 14.1 逐条推出。
2. **de jure 而非 de facto**：全部是标价，不是实付价；折扣能把 token 量放大 5.6—13.8 倍（平台博文），但它不在数据里。
3. **一编码者**：九家的 T 分与数据政策由作者一人编码，无第二编码者；规则写在 3.5 与附录 A，可被推翻。
