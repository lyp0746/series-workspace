# 领域的剖面：四个问题、二十个领域与八十字段的审计

**四问拆解的操作判据、二十个领域的编码，以及「可写性」与「承担者」之间的一条经验关系**

李毅芃 · 2026-10-26 · 工作论文（51 页，CC BY 4.0）

*The Cross-Section of Domains: Four Questions, Twenty Fields, and an Audit of Eighty Cells*

---

## 一句话

把一个复杂领域压成几句话，是当代最流行的智力动作，也最容易退化成口头禅。本文把它固定成四个可判定的问题——**瓶颈、置换、可写性、承担者**，对二十个日常领域逐条编码（80 个字段，全部可复算），得到三件东西：一张瓶颈分布（协调 5、延迟 5、正确 4、容量 3、注意力 2、信任 1、**预算 0**），一张动作通用度表（拆分 19/20，预计算与复制各 17/20，**合并只有 2/20**），以及一条登记为 C 级的经验关系——**越写不出核心的领域，代价越落在分散的、不在场的人身上**（A 级 67% → B 级 31% → C 级 0%）。

## 摘要

四问不是六核心之外的新框架，而是它的一次操作化压缩：Q1 属于「看见」，Q2 属于「选择」，Q3 同时受「讲述」与「临界」约束，Q4 是「讲述」的扩展——置信度分配之外，再加一列**代价分配**。

二十个领域（急诊分诊、法律诉讼、临床试验、供应链、城市规划、金融风控、新闻编辑、外交谈判、农业种植、军事后勤、博物馆策展、婚礼策划、体育训练、图书馆分类、软件架构、烹饪、编程面试、保险定价、教材编写、城市应急管理）的编码给出四个结果。**第一**，瓶颈分布不均：协调与延迟并列最常被付费，预算是「次瓶颈的常客、主瓶颈的陌生人」。**第二**，动作通用度极不均：拆分近乎普遍，合并近乎不用——因为合并把两种失败模式焊在一起。**第三**，可写性呈纺锤形（A 6／B 13／C 1），唯一的 C 级是外交谈判。**第四**，可写性与承担者的在场性同向（67%→31%→0%），本文只把它当作描述性关联，明确拒绝 p 值。

两处自我限制写在正文而非脚注：全部字段是**规范读数**（de jure），第 6 章列出六个「规范说了、行为没做」的落差；主次瓶颈互换后 **5/20** 的领域会改判——四问是「在一个瓶颈假设下的读数」，不是判决书。九条命题中五条支持、两条部分、一条待检验、一条被本文自己撤回（T9：七类不能穷举）。
